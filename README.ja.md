# 知乎コラムエクスポーター

[简体中文](README.md) · [English](README.en.md) · [Español](README.es.md) · **日本語**

ログイン中のアカウントで閲覧できる知乎のコラムや記事を、学習やバックアップ用に保存するブラウザー拡張機能です。Markdown、オフライン HTML、閲覧用目次、画像を ZIP にまとめます。画面の表示は中国語です。

## インストールと更新

Chrome 120 以降、または Manifest V3 に対応する Chromium 系ブラウザーを使用します。

1. [Releases](https://github.com/Hokkaidoooo/zhihu-column-exporter/releases/latest) から ZIP をダウンロードし、展開します。
2. `chrome://extensions/` を開いて「デベロッパー モード」を有効にし、「パッケージ化されていない拡張機能を読み込む」から、展開した中の `extension` フォルダーを選びます。Windows では `install-extension.cmd` で拡張機能の管理ページとフォルダーを開けます。
3. ツールバーに **知乎付费专栏导出** を固定します。更新時はフォルダーを差し替えて管理ページから再読み込みし、開いていたエクスポート画面も開き直します。

## エクスポートとオフライン閲覧

1. 知乎にログインし、閲覧権限のあるコラムの目次か記事を開きます。拡張機能のアイコンを押し、出力形式を選びます。
2. **开始导出**（エクスポート開始）を押し、画面を表示したまま ZIP の保存を待ちます。
3. ZIP を展開します。HTML を選んだ場合は `index.html`、Markdown は `articles/` から読めます。記事ごとの結果と元の URL は `export-info.json` に記録されます。未完了分はエクスポート画面の **重试未完成** から再試行できます。

標準コラムでは目次の全ページをたどり、おすすめ記事は除外します。ログイン状態で取得した記事 API の応答を検証し、API が利用できない場合、試し読みのみの場合、本文に不一致がある場合は理由を表示し、通常の記事ページを最大 4 つのバックグラウンドタブで読み込みます。ZIP には途中までの結果も保存できます。取得できなかった画像は元の URL が残るため、表示には通信が必要です。目次にあるすべての記事と、ローカル保存対象の画像をすべて取得した場合に `complete: true` が記録されます。

## 権限とプライバシー

`downloads`、`scripting`、`tabs` と、使用する知乎ページおよび `zhimg.com` の画像ホストへのアクセスを求めます。リクエストにはブラウザーの通常のログイン状態を使用します。Cookie 権限は要求せず、Cookie やログイントークンを読み取ったり書き出したりしません。記事を第三者に送信することもありません。ログイン、購読、有料閲覧の制限は回避しません。閲覧権限のある資料のみ、合法的な個人利用のために保存してください。

## ビルドとライセンス

Node.js 22 と npm を用意し、リポジトリのルートで実行します。

```sh
npm ci
npm run check
npm run package
```

パッケージとチェックサムは `dist` に出力されます。テストは合成データで行い、有料記事やアカウント情報は使用しません。[開発ガイド](DEVELOPMENT.md)と[変更履歴](CHANGELOG.md)も参照してください。
